# The joke about the demo

A one-line joke about working beside an AI coding agent, entered in [make.fun's "The joke about the demo" bounty](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112).

The joke: the agent "fixes" a crash by rewriting the whole app — a massive overreaction to one crash — and the app still crashes. Two twists in one line: the absurd overreaction, and the failure. A truth developers recognise: agents over-engineer a small fix and still do not fix the bug.

The program (`main.ts`, Node 22) writes the joke deterministically to `/output/entry.txt`.
